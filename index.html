Sobre Mí

Programador Analista con más de cuatro años de experiencia profesional trabajando con el ecosistema Oracle (SQL, PL/SQL, Forms & Reports) en Central Romana, empresa del sector Agroindustrial en República Dominicana. Mi experiencia se centra en el desarrollo y mantenimiento de aplicaciones empresariales transaccionales, optimización de consultas SQL y procesos de base de datos, así como en el soporte y evolución de aplicaciones basadas en Oracle.

Paralelamente, he desarrollado experiencia práctica en desarrollo backend mediante capacitación y proyectos independientes, utilizando Python (Flask, FastAPI), APIs RESTful, PostgreSQL, Docker, Git, CI/CD y pruebas automatizadas. Esta combinación me permite comprender tanto los entornos empresariales basados en Oracle como las tecnologías utilizadas en arquitecturas backend modernas.

También cuento con experiencia práctica trabajando con Ubuntu Server, Linux, SSH y automatización de procesos. Como parte de un proyecto empresarial, desarrollé un proceso programado que monitorea información de Oracle y la envía periódicamente a un sistema externo mediante una API REST.

Durante el último año he incorporado herramientas de desarrollo asistido por inteligencia artificial a mi flujo de trabajo, utilizando agentes de código, OpenCode, instrucciones estructuradas, Skills y Model Context Protocol (MCP). Como proyecto personal, desarrollé un servidor MCP basado en Python para conectar agentes de IA con entornos de Oracle Database.

Mi objetivo es aprovechar esta combinación de conocimientos para contribuir en proyectos de desarrollo backend, integración y evolución de sistemas empresariales, conectando la lógica de negocio existente con soluciones modernas, mantenibles y bien documentadas.
